# 来源明确的资料补齐

## 公司与地址

卖家ID优先本次目标商品/自然卡片的Buy Box证据，缺项才用第三方。第三方卖家ID与本次不同时，不能套旧卖家名称、国家、公司或配送。

先取Amazon卖家页Business Name/Address。页面不可得时可用按ID精确查询的Sorftime等明确公司名/地址字段写入AA/AB，标第三方及未直接核实；不要把已取得的可追溯资料仅留说明导致主表大量空白。字段provenance.source_type=third_party_database，生成器标浅黄。

品牌、店铺、商标申请人、公司不是同一概念。只有sellerNation不能推断公司。Amazon自营无正式主体/地址证据则留空。按明确国家字段译中文；美国州CA等不能误当其他国家。代码与明确地址国家冲突时留空并记证据。

卖家ASIN数量可用工具报告店铺总商品数，说明计数粒度是否已知；样本内数量须明示。卖家最佳自然排名取当前主表同卖家ID的最小排名，注明样本口径。

## 商标

按实际品牌而非过时拼写检索、缓存、归一化精确匹配。保存局、申请/注册号、类别、状态及状态日期，有官方证据则优先。不能只因不是预设一个类别就丢掉已有主体记录，也不能据跨类别同名认定属于本商品。

- 注册记录主体唯一但归属未核实：同名注册记录候选：<主体>。
- 多个同名注册主体：同名候选：<主体一>；<主体二>，不任选一家。
- 仅申请中：申请人：<主体>（申请中），不作已注册持有人。
- 仅失效/终止：历史记录主体：<主体>（已失效/终止），不代表当前有效权利。
- 无匹配记录：留空，说明本次未返回，不表述成没有权利。

AH只填对应候选的可追溯国家；多主体国家不同须明确列为候选，不伪装唯一国家。代码/地址冲突留空；部分候选冲突须说明已知国家覆盖。

AG/AH provenance.source_type=third_party_trademark_candidates。AI写短状态；完整类别、编号、状态、证据、歧义放 `_trademark_details`，生成器写说明。商标候选不能自动作卖家公司。

## 日期、销量及缺失

availableDate可作注明来源的第三方上架日，createdTime不能代替。最早返回历史记录可能只是窗口起点；不能证明上架日时保留未知。确用近似日时标 `_listing_date_approx: true`，不伪称真实。

页面购买量带+仅为下限。估算只有周期、粒度明确匹配目标ASIN才补主表；父体或同父相同units留副表/证据，不当子体销量。

空值不是补查结束的理由，应尝试已授权且合适的来源并记录真实缺口；同时不能为了消除空白编造事实。交付报告覆盖及来源性质，而非只说35列已完成。
