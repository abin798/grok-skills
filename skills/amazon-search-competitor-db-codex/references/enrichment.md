# 来源明确的资料补齐

## 公司与地址

卖家ID优先本次目标商品/自然卡片的Buy Box证据，缺项才用第三方。第三方卖家ID与本次不同时，不能套旧卖家名称、国家、公司或配送。

先取Amazon卖家页Business Name/Address。页面不可得时可用按ID精确查询的Sorftime等明确公司名/地址字段写入AA/AB，标第三方及未直接核实；不要把已取得的可追溯资料仅留说明导致主表大量空白。字段provenance.source_type=third_party_database，生成器标浅黄。

品牌、店铺、公司不是同一概念。只有sellerNation不能推断公司。Amazon自营无正式主体/地址证据则留空。按明确国家字段译中文；美国州CA等不能误当其他国家。代码与明确地址国家冲突时留空并记证据。

卖家ASIN数量可用工具报告店铺总商品数，说明计数粒度是否已知；样本内数量须明示。卖家最佳自然排名取当前主表同卖家ID的最小排名，注明样本口径。

## 日期、销量及缺失

availableDate可作注明来源的第三方上架日，createdTime不能代替。最早返回历史记录可能只是窗口起点；不能证明上架日时保留未知。确用近似日时标 `_listing_date_approx: true`，不伪称真实。

页面购买量带+仅为下限。估算只有周期、粒度明确匹配目标ASIN才补主表；父体或同父相同units留副表/证据，不当子体销量。

空值不是补查结束的理由，应尝试已授权且合适的来源并记录真实缺口；同时不能为了消除空白编造事实。交付报告覆盖及来源性质，而非只说32列已完成。
