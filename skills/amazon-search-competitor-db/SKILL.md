# 亚马逊搜索词竞品表

用户只发一个搜索词（例如 "napkin rings"）时，就是要这张完整的表。直接开工，不用确认；回复全部用中文。本技能附带的文件在 `/home/box/agent-data/amazon_competitor_kit/`（从本仓库 scripts/ 与 ref/ 下载）：
- 脚本：`embed_v2.py`、`add_links_v2.py`
- 富数据模板：`ref/xl/richData`

## 1. 抓取（amazon.com 美国站）
- 用 curl_cffi 抓搜索结果第 1–3 页，只要自然排名，剔除所有 Sponsored 和广告组件。
- 按 ASIN 去重，排名在 3 页之间连续编号，同时记录页码和页内位置。
- 进每个商品的详情页，取标题、品牌、价格、原价、评分、评论数、BSR（大类和小类分开）、库存状态、变体（另做「变体明细」表）、Buy Box 卖家 ID，并下载主图。
- 「bought in past month」只保留数字。

## 2. 卖家精灵 MCP 补数据
- 地址 `https://mcp.sellersprite.com/v2/mcp`，请求头 `secret-key` 取环境变量 `SELLERSPRITE_MCP_KEY`，绝不打印密钥。成功调用一次扣 1 点，尽量批量。
- `asin.detail`：每批 20 个，取上架时间 availableDate、卖家、配送方式、父 ASIN、记录更新时间。
- 近一月销量为空的，用 `asin.list` 的 monthlySales 估算补上，这些格子用浅橙底 `FCE4D6` 标出。
- 上架时间仍为空的，用 `keepa.trend` 的最早记录近似补上。

## 3. 卖家主体
- 卖家名称和国家取自卖家精灵。
- 公司全称和地址并发抓取亚马逊卖家资料页 `https://www.amazon.com/sp?seller=ID`；卖家精灵不提供这两项。亚马逊自营的地址留空。
- 美国商标局（USPTO）的商标持有人及其国家可以一起查，商标持有人国家写成中文，美国各州统一写「美国」。

## 4. 「竞品明细」表结构（35 列，顺序固定）
1. **排名与商品：** 自然排名、页码、页内位置、ASIN、主图、标题、品牌
2. **价格与销量：** 价格、原价/参考价、折扣、近一月销量、上架时间
3. **评价与类目：** 评分、评论数、大类BSR排名、大类、小类BSR排名、小类名称、变体数量、父ASIN、库存状态
4. **卖家：** 卖家、配送方式、卖家精灵数据更新时间、卖家ID、店铺名称、公司主体、公司地址、主体所在国家/地区、卖家ASIN数量、卖家最佳自然排名、卖家主页
5. **商标：** 商标持有人、商标持有人国家/地区、商标信息

格式规则：
- 表头只写中文，不带括号和英文。
- 价格格式 `$#,##0.00`；折扣是正数比率，等于 1 - 价格/原价，格式 `0%`，原价不高于现价时留空。
- 上架时间格式 `yyyy-mm-dd`；整数列一律用格式 `0`。新加列时显式设置数字格式，否则会继承旁边的日期格式。
- 库存状态统一写成「有货」「库存紧张（剩N）」「无购买框」。
- ASIN 列是纯文本。主图列是嵌入单元格的图片（Place in Cell），点击打开 `https://www.amazon.com/dp/{ASIN}`；卖家主页列是可点击的超链接。
- 冻结窗格设在 F2，开启全表筛选。

其他 sheet：
- 「变体明细」：表头只写中文。
- 「说明」：中文写清搜索词、抓取时间（北京时间）、配送邮编、广告剔除规则和各列的数据来源。

## 5. 嵌入图片的流水线（关键）
- openpyxl 重新保存最终文件会毁掉嵌入图片。所有修改都先在中间文件上用 openpyxl 改，主图列先放 ASIN 文本占位（inlineStr），然后跑 `embed_v2.py`（把主图列的占位单元格换成 `t="e" vm=` 的图片单元格，图片取 `napkin_imgs/{行号}.jpg`），再跑 `add_links_v2.py 中间嵌图文件 中间文件 最终文件`（主图链接和卖家主页链接写进同一个 sheet rels 文件，worksheet 根节点要声明 xmlns:r）。
- 脚本里写死了行数（2–144）和列，要按新的商品数量调整。
- 最后校验：图片单元格数等于商品数，超链接数等于商品数加有卖家主页的行数。

## 6. 交付
- 文件名固定为 `当季热销品竞品数据库--<搜索词><YYYYMMDD>.xlsx`：搜索词照原样保留空格，日期取北京时间当天，紧跟在搜索词后面，中间不加分隔符。比如 `当季热销品竞品数据库--napkin rings20261114.xlsx`。文件保存到 `/workspace/`，作为附件发出。
- 再用几句中文说明：商品数量、主要卖家所在国家、头部主体，以及没补上的数据、卖家精灵用了多少点数。
